# Tweeting Turtle Project Website

Static website for the Tweeting Turtle Project — open-source sea turtle conservation in Malaysia.

## Deploy to GitHub Pages (Free)

1. Create a new repository on GitHub (e.g. `tweeting-turtle`)
2. Upload these files (`index.html`, `styles.css`)
3. Go to **Settings → Pages**
4. Under **Source**, select `main` branch → `/ (root)` → Save
5. Your site will be live at `https://YOUR-USERNAME.github.io/tweeting-turtle`

## Customise

- **Add team members** — find the `#contributors` section in `index.html` and copy the contributor card template
- **Add updates** — find the `#updates` section and add new `<article class="update-card">` blocks
- **Embed Adafruit IO** — find the `data-embed-placeholder` section and replace with your dashboard `<iframe>`
- **Add photos** — place images in an `images/` folder and reference them in the HTML
